# Part03 K線篇 — 規則筆記

## 3-1 K線基本 / 4+1 元素
- 紅K：收>開；黑K：收<開。K 線顏色≠當天漲跌（需與昨收比）。
- 同樣漲 1 元：紅K上漲=多方強次日易漲；開高走低黑K=賣壓重次日易跌；長上影紅K=上有壓力，看次日開盤。
- 週K=週一開到週五收；月K同理。日/週/月趨勢可不同（範例：日線多頭回後買上漲、週線空頭反彈遇壓、月線多頭）。
- 「4+1」元素：開、收、高、低 + 二分之一價 =(高+低)/2。
  1. 開盤價：反映消息面與主力企圖；關鍵轉折位置次日開盤定強弱。高檔大量長紅後次日開低 → 主力要回檔；低檔長黑後次日開高收紅 → 主力要反彈；接近前高開低收黑 → 續盤整；開高跳空帶大量 → 要突破。
  2. 收盤價：決戰結果；收盤突破昨高=買方轉強；跌破昨低=賣方轉強。前日高=壓力、前日低=支撐。
  3. 最高價：空方防守線（次日壓力）；最高價到前壓力未過或過了又拉回留長上影 → 壓力訊號；次日被突破=多方轉強。
  4. 最低價：多方防守線（次日支撐）；到前支撐留長下影 → 支撐訊號；次日被跌破=空方轉強。
  5. 二分之一價=當日平均成本：大量長紅日後跌破其 1/2 價 → 多方轉弱；高檔大量長紅 1/2 價被跌破 → 做頭機率大；低檔大量長黑 1/2 價被突破 → 止跌機率大。走勢中出現大量長紅/長黑都要注意其 1/2 價。
  - 次日大量長黑跌破前日大量長紅 1/2 → 次日易回檔/假突破；低檔大量長黑後次日大量紅K突破其 1/2 → 次日易反彈。

## 大量長紅/長黑 K 的支撐壓力（關鍵K棒）
- 大量長紅 K 日後回測：3 個支撐價位 — ①最高價（股價在上=最強支撐）②1/2 價（平均成本）③最低價（最弱支撐）。
  - 黑K跌破長紅最高點 → 攻擊減弱，須 3~5 日內站回，否則注意轉折向下。
  - 跌破 1/2 價 → 多方氣勢被破壞。
  - 跌破最低點 → 多空易位，該長紅變日後壓力。
- 大量長黑 K：3 個壓力價位 — ①最低價（股價在下=最強壓力）②1/2 價 ③最高價（最弱壓力）。紅K收盤突破最低點→空方減弱；突破 1/2→空方被扭轉；突破最高點→多空易位，長黑變支撐。
- 空頭下跌中長黑無止跌訊號不可低接；連續長黑後出現爆量或窒息量易反彈，紅K收盤過前日高可短線搶反彈。
- 多頭回檔出現爆量長黑 = 關鍵K棒；之後大量紅K突破其 1/2 → 轉強；突破其最高點 → 續漲可做多。

## K 線橫盤
- 連續 ≥3 根 K 線未突破前一根高點也未跌破低點 → K 線橫盤。
- 中長紅 K 收盤突破橫盤上頸線 → 確認向上（多頭時為買點）；中長黑收盤跌破下頸線 → 確認向下（空頭時為空點）。

## K 線轉折與趨勢
- 研判 K 線前先確認：①趨勢（多/空/盤整）②K 線位置（低檔/高檔/行進中/接近壓力支撐/關鍵突破跌破）③成交量變化。
- 多頭轉折訊號：大量長紅突破底部盤整+4線多排→開始做多；高檔長下影變盤線→轉折下跌訊號；紅K收盤突破變盤線→續漲；高檔大量長黑→轉折下跌；大量紡錘變盤K→轉折；回檔後紅K收盤突破 MA5 → 續漲做多。
- 空頭：高檔大量長黑/長上影 → 轉折；大量長黑跌破前低→空頭確認順勢空；低檔長紅→止跌反彈；連續 3 天變盤K線→止跌；黑K收盤跌破盤整下頸線→續跌。

## 3-2 高檔反轉 K 線（多單出場 / 空方進場訊號）
### 高檔變盤線（單一 K）
- 墓碑線、長 T 線、十字線、紡錘線、反鎚線（長上影小實體）、槌子線（長下影小實體）、跌停線、長黑線。
- 轉折機率更高的條件：①高檔出現 ②高檔爆大量 + 價量背離 + KD 死叉 ③遇壓力位置爆量收盤未過壓 ④變盤線次日走勢要特別注意。

### 高檔 紅K+黑K 6 種組合（中長 K = 漲跌幅 ≥3%）
1. 基本型態 長紅長黑：高檔止漲；多頭起攻位置小心騙線；空頭中=反彈結束訊號。
2. **長黑遭遇（一日封口）**：黑K開高走低收盤接近紅K收盤。6 組中最弱，僅視為止漲，需再觀察 1 天；爆大量則轉折機率大，不可追多；空頭反彈出現=做空機會。
3. **長黑覆蓋（烏雲罩頂）**：次日開高創新高，收在最低附近且進入紅K實體。未達紅K 1/2 → 較弱需觀察；跌破 1/2 → 反轉訊號；跌破紅K實體低點 → 變成吞噬。H/L 為壓力支撐；之後在 L~H 間橫盤常為做頭；爆大量更易反轉。
4. **母子懷抱（不懷好意）**：中長紅（母）+ 次日不過高不破低的黑K（子）。止漲訊號，注意次日；子線為變盤線（十字）時反轉力更大。
5. **長黑吞噬（主力出貨）**：黑K實體完全包覆前一根紅K實體，開高走低收盤跌破前日低 → 最強反轉訊號之一。當日/前日大量→更強。短線連漲或急漲獲利 ≥15% 出現吞噬 → 一日反轉機率高，多單出場或減碼一半。一根黑K吞掉前 2~3 根低點=3 線反黑。高檔爆量吞噬後再漲到此處=逃命波不可追多，易形成頭頭低。
6. **長黑貫穿（一路向下）**：開盤即下跌，收盤跌破前一日中長紅實體最低點 → 反轉最強訊號。貫穿當日/前日大量更強；短線急漲 ≥15% 出現貫穿 → 多單立刻出場。
### 高檔夜星（紅K + 變盤線(s) + 黑K）
- 型態：孤島夜星、母子變盤、雙星變盤、雙鴉變盤、群星變盤。右邊黑K完成=轉折確認。同時爆大量 → 機率大增、跌勢強；中間變盤線越多，下跌時空方控盤越久。
- 夜星被破壞：下跌中長黑高點被紅K突破 → 轉多方主控（常見於多頭回檔）。

## 3-3 低檔反轉 K 線（做多 / 空單回補訊號，與 3-2 鏡像）
- 低檔變盤線：墓碑、長T、十字、紡錘、反鎚、吊人、漲停線、長紅線。配合：低檔爆量或窒息量、價量背離、KD 黃金交叉、遇支撐 → 轉折機率高；需看次日是否上漲確認。
- 低檔 黑K+紅K 6 種：
  1. 基本型：空頭低檔止跌；盤整假跌破；多頭回檔結束訊號（在空頭起跌位置小心騙線）。
  2. **長紅遭遇**：最弱，需再觀察 1 天；空頭無量次日向上=弱勢反彈，爆量=強勢反彈（逆勢需小心）；**多頭回檔出現遭遇 + 次日出量上漲 = 續漲做多買點**。
  3. **長紅覆蓋**：開低破新低，收盤進入黑K實體；突破 1/2 =強覆蓋，反轉可能高；H/L 為支撐壓力。
  4. **母子懷抱（光明在望）**：長黑母 + 不過高不破低的紅子；黑K高點被突破=反彈確認；母量>子量時次日需放量上漲；次日開高易反轉，開低易續跌；子線為變盤線 → 易形成晨星。
  5. **長紅吞噬**：雙K向上轉折最強，空單立刻回補；吞噬當日/前日大量或窒息量更強；一根紅K吞前 2~3 根高點=3 線反紅；爆量吞噬K日後為重大支撐（易形成底底高）。
  6. **長紅貫穿**：開高走高收盤突破前一日黑K高點；配合大量易 1 日反轉；短線急跌獲利 ≥15% 出現 → 空單立即回補。
- 低檔晨星（黑K+變盤線+紅K）：孤島晨星、母子變盤、雙星變盤、雙肩變盤、群星變盤；爆大量更強；晨星後長紅低點被跌破 → 結構破壞（常見於空頭反彈）。

## 3-4 單一 K 線（實體大小分類）
- 長紅：開→收 > 6.5%（多方最強）；中紅：3.5%~6.5%；小紅：< 3.5%。（黑K同理）
- 多頭中紅K位置：打底期間量增（主力承接，尚不攻）；打底完成收盤突破底部盤整+攻擊量=多頭確認長紅；行進中惜售量縮；回檔不破前低出現上漲紅K=做多；盤整末端大量紅K突破=攻擊；高檔/連續急漲紅K + 爆量 + 價量背離 + 遇壓不漲 = 主力出貨；高檔盤頭區大量紅K = 分批出貨。
- ★ **大量紅K可以買**：①空轉多第 1 次過前高的多頭確認大量長紅（均線 3 線多排向上）②多頭回檔止跌回升大量長紅 ③盤整完成向上突破的大量長紅 ④型態確認突破的大量長紅。
- ★ **大量紅K不能買**：①日線上漲 3 天以上高檔的大量紅K ②接近壓力位置前的大量紅K ③空頭反彈的大量紅K ④多頭回檔跌破月線，在月線下的上漲大量紅K（要等站上月線）⑤多頭回檔跌破前低後的上漲大量紅K（趨勢已變盤整）。
- 黑K：空頭低檔打底盤整中的黑K不可認為跌深去做多；多頭行進中黑K量縮=正常回檔；多頭高點黑K + 大量/爆天量 → 主力出貨可能大，次日下殺立刻出場。空頭：頭頭低第2頭長黑易轉空頭；初跌段黑K通常出量；下跌中無止跌訊號不能低接；連續長黑後爆量或窒息量 → 紅K收盤過前日高可短線搶反彈；空頭盤整黑K跌破 → 做空機會。
- 紡錘線：影線未超過實體 1/2，多空拉鋸；次日再看。
- **槌子/倒鎚**：小實體在上或下（紅黑不重要），影線 ≥ 實體 2 倍。高檔出現 → 次日向下跳空大跌或收盤跌破其最低點 = 轉折向下確認。低檔出現 → 次日向上跳空大漲或收盤突破其最高點 = 轉折向上確認。伴隨大量 → 轉折機率更高。

## 3-5 K 線組合
- **上升三法**（續漲）：中長紅 → 1~數日小黑/小紅/變盤（收盤不破中長紅低點）→ 中長紅突破左邊紅K高點。多頭中持多續抱；空頭低檔盤整時出現大量上升三法 → 多方轉強、趨勢可能改變。
- **一星二陽**（空頭低檔易反轉）：低檔黑K + 小變盤 + 大量紅K，之後回檔再一星二陽 → 多頭確認。
- **上漲連 3 紅**：3 根連續大量紅K實體 → 強力上漲訊號；數量越多力量越大；跳空連紅更強；空頭低檔出現=強力反彈/打底；**底部打底第 2 支腳出現連 3 紅 = 強勢多頭起動**。高檔連 3 紅都帶長上影 → 注意變盤；高檔連 3 紅 + 爆量/價量背離 → 注意反轉。
- **下降三法**（多頭高檔改變趨勢）、**一星二陰**（高檔易反轉）、**下跌連 3 黑**（空頭啟動；低檔連 3 黑帶長下影=探底，爆量或 KD 背離 → 易反彈）。

## 3-6 ★ K 線多空操作戰法（最簡規則，可回測）
- 多頭：進場=收盤前確認股價突破前一日高點買進；續抱=未跌破前一日低點；出場=收盤跌破前一日低點；停損=進場當日 K 最低點（不超過 7%）。
- 空頭：進場=跌破前一日最低點放空；停損=進場 K 最高點（≤7%）；續抱=未突破前日高；回補=突破前一日最高點。
- 範例中下降軌道線：跌破下降軌道支撐長黑 → 加速下跌（詳見 Part05）。
