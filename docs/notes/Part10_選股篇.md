# Part10 選股篇 — 規則筆記

## 10-1 投資與投機
- 技術面 2 句話：①公司沒有好壞，只有多空 ②股價沒有高低，只有多空（多頭不猜頭、空頭不摸底）。例：金麗科 3228 營收衰退仍盤整突破 + 4 線多排上漲 413%。
- 投資：長期領息、基本面、價值區間承接、股池=台灣50/中型100。
- 投機：賺短期價差、技術面、**中小型股、技術線形好的強勢股**。

## 10-2 基本面選股（投資目的）
- 基本資料、經營績效（營收、獲利率、年增率、淨值、本益比、ROE）、財務結構、盈餘分配、價值評估、經營者理念。
- 結論：基本面估長期趨勢，技術面判斷進出時機。→ 網站可在個股頁顯示 營收年增/毛利率/EPS 作輔助（FinMind 免費有月營收、財報）。

## 10-3 投機目的：技術分析選股 7 法
### ① 六六大順選股（研判順序：趨勢 → 位置 → K線轉折 → 均線 → 成交量 → 指標）
1. 趨勢：頭頭高底底高做多；頭頭低底底低做空；盤整退出觀察。
2. 位置：多頭（打底/初升/主升/末升；起漲/上漲行進/短線高檔/遇壓/回檔/止跌/遇撐/突破）；空頭鏡像；盤整（開始/型態/末端/突破或跌破）。
3. K線轉折：多頭關鍵K=多頭確認、型態確認、多頭起漲、突破高點、過壓力K線、大量長紅；價漲、量增(>昨 1.3 倍)、中長實體紅K收盤確認。空頭：價跌，量有無皆可（量增殺力更大），中長實體黑K收盤確認。
4. 均線：多頭最少 3 線多排向上、股價在月線上；空頭最少 3 線空排向下、股價在月線下；盤整均線雜亂退出觀察。
5. 成交量：多頭價漲量增價跌量縮（起漲量 vs 壓力量、高檔/壓力前量大非福、看日後價決定量的定義、價量背離）；空頭價漲量縮價跌量增非必然（頭部量、急跌/強支撐前放大量）。
6. 指標：高低檔金叉/死叉、多空排列、背離。

### ② 4基10技選股法
- 4 基：①產業類股=當下熱門 ②**股本 50 億以下中小型股** ③營收成長、盈餘、全年績效 ④籌碼=法人買賣超。
- 10 技（日線+週線）：趨勢、位置、均線(3/4/6 線多空排)、K線強弱、成交量(打底量/起漲量/高檔量/遇壓量/頭部量/起跌量/低檔量/支撐量/換手量/騙線量)、型態(底/頭/中繼)、支撐壓力、指標(MACD/KD)、背離(量價/指標)、獲利目標與操作定法(短中長線)。
- ★ **選股評量表格**（可直接做成個股頁檢查表）：日期、股票、營業項目、股本、基本面；波型(月/週/日線)、位置(週/日)、K線(週/日)、均線/切線、成交量(週/日)、指標(週MACD/週KD/日MACD/日KD)、支撐、壓力、背離、融資融券(融資/融券/融資比)、法人買賣超、型態、其他 → 策略。
  - 範例 安國 8054 (2023/9/15)：週線底底高突破 MA20/60、日線多頭確認；週量比前週大 3 倍；週 MACD 0 軸上黃金交叉；日 4 線多排；圓弧底；策略：待突破壓力 38.3（週線多頭確認）做多，20 張分配 10 張短線守 MA5、10 張長線守 MA20，長線目標 67.8 約 +77%。

### ③ 淘汰法（11 種要避開做多的股票 → 做成過濾器）
1. 沒走出底部（趨勢未完成、均線未多排）。
2. 重壓不過、跌破 MA5（帶大量的壓力不過）。
3. 上漲一波後趨勢不明（上有重壓、下有支撐的區間震盪）。
4. 沒有量能（上漲中量明顯縮小或量價背離）。
5. 大幅上漲過高（漲達 1 倍以上，呈盤整趨勢要立刻出場）。
6. 遇壓力大量長黑（壓力線附近多次大量長黑）。
7. MACD 或 KD 背離 + 趨勢頭頭低 → 立刻出場。
8. 三大法人連續賣超（下跌時爆量長黑或連 3 黑大量賣壓；外資投信都在賣）。
9. 頻頻爆大量股價不漲。
10. 看不懂的股票。
11. 有基本面、沒有技術面。
- 結論：出現明確訊號才順勢操作（空頭反彈不做多）。

### ④ 特別報價選股法（每日收盤後 SOP）
1. 看當日「漲幅前 100 強勢股」「量放大股（現量/昨量前 100）」「跌幅前 100 弱勢股」。
2. 去除成交量 < 1,000 張。3. 去除股價 < 5 元。
4. 先看日線初選符合做多條件；5. 注意類股群聚現象；6. 發覺強勢題材股；7. 再看週線仔細研判。
8. 建立「鎖股資料夾」按強弱排序；9. 每日檢視鎖股資料夾做汰換。
### ⑤ 盤中選股設定（e01 系統）：爆量股、開高強勢、即將漲停、股價翻紅、連續漲停打開、連續跌停打開、1 分鐘內漲 2%、連 3 筆外盤大量、收盤前 1 小時精選次日續漲股。（需即時資料，P5 之後）
### ⑥ 未卜先知選股法（底部鎖股）
- 觀察一、底部盤整鎖股：空頭下跌 MA20 下彎，低檔爆大量止跌（黑K+紅K），之後底部盤整、回測不破低點出現大量紅K（數次），MA20 走平 → 鎖股等突破壓力線。
- 觀察（圖 10-3-19）：趨勢反轉多頭前，低檔爆大量後上漲，再下跌收盤無法跌破前低支撐 → 底部盤整開始鎖股；大量紅K突破底部盤整 → 多頭確認；3 線多排向上做短多，4 線多排向上規劃長多。
- 觀察二、**底部 2 個月均線糾結鎖股**：空頭低檔 2 個月不漲不跌小幅震盪（均線糾結），大量紅K突破盤整 → 短多或長多（例：國產 2504、茂綸 6227）。
- 觀察三、**空頭反彈突破月線**：強力反彈突破月線、股價維持在月線上整理 → 鎖股；月線上揚 + 大量紅K突破橫盤 → 做多。
- 觀察四、**空頭反彈突破前高**：低檔大量強力反彈突破前高 → 鎖股；第 2 支腳在月線之上出現大量長紅、月線上揚 → 做多（例：雙鴻 3324）。
- 觀察五、**強勢型態**：頭肩底、圓弧底等型態成形 → 鎖股；大量長紅突破型態頸線確認 → 做多；型態目標價=等幅測量。
### ⑦ ★「強勢飆股」第 2 波選股法
- 鎖住當下熱門題材、強勢上漲第 1 波高檔的股票，等回檔修正後第 2 波上漲。
- 程式化：多頭確認 + 第 1 波攻擊量上漲（漲幅大）→ 高檔橫盤/小幅回檔量縮（不破第 1 波起漲區、MA10/MA20 支撐）→ 攻擊量紅K突破整理區高點 = 第 2 波進場（例：富世達 6805、欣大健康 4198）。

## 10-4 底部強勢反轉圖形（鎖股位置）
1. **底部狹幅盤整**：底部 ≥2 個月狹幅盤整（範例 2.5~4 個月），鎖住，爆大量紅K突破時進場（華建 2530、台端 3432、晶睿 3454、名軒 1442）。
2. **空頭強勢反彈**：股價在月線上橫盤，鎖大量紅K突破橫盤時進場（聯詠 3034、精材 3374）。
3. **雙盤底**：第 1 次底盤整、第 2 次底盤整（不破第 1 次底），大量紅K突破第 2 盤整進場（聯電 2303、由田 3455）。
4. **緩步上漲後的攻擊位置**：緩步沿均線上漲後突然出現大量長紅K發動攻擊 → 轉強買進（一詮 2486、裕民 2606）；高檔爆天量 → 賣出。
5. **緩漲上升突破上升軌道做多**：緩漲過程中大量長紅K突破緩漲的上升軌道線 → 進場（中光電 5371、訊舟 3047）。

## 10-5 ★ 股市交易工作重點（每日收盤後 SOP）
- 每天收盤後看當日 **漲 ≥3.5% 強勢股、跌 ≥3.5% 弱勢股**（至少前 50 檔），去除線形不好、看不出方向、成交量太小、價格太低（地雷股）。
- 進場做多前提：①大盤站上月線、月線上揚 ②類股多頭且比大盤強，選前 3 強類股 ③找龍頭股與強勢類股中的強勢個股 1~3 檔 ④未來有發酵題材（AI、6G 光纖、節能、國防…）。
- 進場做空前提：①大盤在月線下、月線下彎 ②類股空頭，選最弱前 3 類股 ③弱勢類股個股 1~3 檔 ④漲多領先下跌或無基本面炒作超漲下跌。
- 看圖 17 重點：1 當日波浪型態是否符合多/空架構；2 分時走法（開盤漲停最強、9:10 前次之、9:30 前漲停強；13:20 後漲停看次日能否續強；開盤跌停最弱）；3 價量配合 + 三大法人 + 融資融券（洗盤再漲？）；4 週線方向與月線圖形；5 日/週 KD；6 近 3~5 日 K 線型態；7 是否主流/題材/應景/轉機/軋空股；8 均線排列與位置；9 盤整或發動；10 預估獲利空間與風險控制；11 強勢股中找空頭反彈可做空、弱勢股中找多頭回檔可做多；12 明日可進場標的最佳 3~5 檔；13 資金分配；14 擬定策略；15 新類股啟動與輪動；16 主流類股轉弱訊號；17 建立強勢股資料庫（財庫）。
