# Part09 缺口篇 — 規則筆記

## 9-1 缺口基本
- 向上跳空缺口：今日最低價 > 前一日最高價（缺口=前日高~今日低）。向下跳空：今日最高 < 前日最低。
- 成因：①突發利多/利空（短期震盪，政策面影響較遠）②**主力強力做多/做空（最重要，通常伴隨大量/爆天量）**③除權息、增減資（意義不大，需排除！）。

## 9-2 向上缺口
### 跌深反彈的向上跳空缺口
1. 反彈要能過前高；沒過=空頭反彈，不可進場。
2. 跳空強勢反彈突破月線或過前高 → 列入打底觀察股。
3. 前面連續 3 天以上中長黑急跌或連續跌停且爆大量，收盤前確認當天收盤突破前一日高點 → 可少量搶反彈，設停損與停利策略。
### 低檔島型反轉（向下竭盡缺口 + 向上跳空缺口，中間 K 線成孤島）
- 低檔出現=大漲前兆，空單立刻回補。孤島可 1 根、2~3 天或較多天盤整；盤整日越多日後行情越大。
- 型態：①低檔反彈島型反轉（之後底底高）②碎步上漲的島型反轉 ③低檔島型反轉多頭（突破成多頭確認）。
### 底部盤整區的缺口 = 區域/普通缺口：1~2 天就封閉，意義不大。
### ★ 打底完成的向上突破缺口（強力買進訊號）
1. 需明顯大量配合且量持續增加 → 通常續漲，短時間不會回補。
2. 缺口開口越大越強（跳空漲停最強）。
3. 缺口在 3 天內跌回起漲點回補 → 小心假突破；按紀律買進但設好停損。
- 突破後缺口常成為日後支撐（缺口支撐）。
### 上漲行進中的缺口
- 不回補=強勢續漲；幾天內就回補 → 失去攻擊功能，但多頭架構未變仍為多頭只是轉弱。
- **逃逸缺口/量測缺口**：上漲一段後在關鍵位置再跳空 → 經驗上還有約等幅於前段漲幅的行情。
### ★ 竭盡缺口（高檔/末升段）
- 判斷：①位置=連續上漲高檔或波段末升段 ②爆量=缺口附近 1、2 天出現爆量長紅或跳空紅K，之後量明顯縮、小漲/價平/價跌 ③回補=缺口出現後 2、3 天股價不漲或回跌回補缺口。
- 缺口序列：突破缺口 → 逃逸缺口 → 竭盡缺口 → 向下跳空/島型反轉 → 空頭確認。

## 9-3 向下缺口（鏡像）
- 漲多回檔的向下跳空：沒跌破前低=多頭回檔不可空；跌破前低底底低、反彈未過前高頭頭低 → 空頭確認；**連續 3 天以上中長紅急漲或連續漲停且爆量後向下跳空，收盤確認跌破昨低 → 可少量放空，停損=進場黑K高點，用 K 線戰法停利**；漲多向上缺口後幾天內又大量向下跳空 = 高檔島型反轉，易強勢回檔，少量做空。
- 高檔島型反轉：大跌前兆，「必殺做空」好機會；盤整日越多行情越大。
- **做頭完成的向下跌破缺口**：不需要大量配合（與向上突破不同）；開口越大越明顯；3 天內漲回起跌點回補 → 小心假跌破。
- 下跌中逃逸缺口 → 約等幅下跌；末跌段竭盡缺口：位置低檔、附近 1~2 天爆量長黑/跳空黑K後量縮、2~3 天內不跌或回漲回補缺口。

## 9-4 缺口支撐壓力（★ 4 個關鍵價位，可程式化）
- 大量向上缺口 → 日後回檔支撐強；跌破缺口下沿壓力也大。無量向上缺口（例：無量漲停）支撐弱，反轉時常急跌。股價進入有大量的缺口會多空交戰、震盪加大。
- 向上缺口的 4 個價位：
  1. **上高**（缺口上漲後紅K高點）最強支撐：收盤跌破 → 多頭氣勢轉弱。
  2. **上沿**（缺口上漲後紅K低點=缺口上緣）次強：跌破 → 進入缺口多空拉鋸；被回補 → 強勢多頭變一般多頭。
  3. **下沿**（缺口前紅K高點=缺口下緣）較弱：收盤跌破 → 缺口被跌破，多頭氣勢完全轉弱。
  4. **下底**（缺口前紅K低點）最弱：跌破 → 多空易位，空方主導。
- 向下缺口鏡像：下底(最強壓力) → 下沿 → 上沿 → 上高(突破=空多易位)。

## 9-5 進階
- **缺口之上見長紅K**：回跌不破缺口上沿 → 以做多為主，拉回做多；在長紅 1/2 價之上、收盤價之下高處橫盤 = 強勢整理隨時會漲；在長紅收盤之上橫盤 = 強勢整理，發動時可追。**強勢橫盤最易在第 1、3、5、8、13 日的次日發動**（費波那契）。
- 缺口之下見長黑K（鏡像）。
- **真封口**：向上缺口近日內出現大量實體黑K，收盤到缺口下沿或跌破下沿 → 被真封口，缺口失去支撐/壓力特性（轉弱）。向下缺口鏡像（大量實體紅K收盤到上沿或突破）→ 轉強。
- **假封口**：回補的黑K留長下影、或回補時呈大量紅K、或量縮 → 易是假封口（仍有效）。向下缺口鏡像（長上影、大量黑K、量縮）。
- **多空交鋒缺口**：上有向下缺口壓力、下有向上缺口支撐 → 區間震盪，待一方被回補突破/跌破才明朗。
- ★ **向上 3 日 2 缺口要大漲**：打底第 1 或第 2 支腳出現上漲連 3 紅且 3 日出現 2 缺口 → 底部完成時強勢多頭股要鎖股做多；起漲位置 3 日 2 缺口 = 主力強力做多宣示，缺口沒被回補易大漲；行進中 3 日 2 缺口只要高檔爆量後不跌易再漲一波；**高檔 3 日 2 缺口 + 爆大量 → 注意不漲或下跌、缺口是否被回補（反轉訊號，如次日大量吊人線）**。
- 向下 3 日 2 缺口要大跌（鏡像）；低檔 3 日 2 缺口 + 爆量 → 注意反彈。
- **隱形缺口**：次日開盤價與前一日收盤價跳空（K 實體間跳空，但影線有重疊），收盤時沒回補此跳空 → 同樣具缺口支撐/壓力與轉強/轉弱功能。程式定義：向上隱形缺口=min(O,C)_today > max(O,C)_yesterday 且非真缺口。
