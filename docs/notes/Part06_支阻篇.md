# Part06 支阻篇 — 規則筆記

## 6-1 支撐壓力觀念
- 支撐=某位置大量買進形成獲利籌碼；壓力=大量賣出形成套牢籌碼。皆非絕對，需技術面反應確認（例：多頭回檔到上揚月線，沒確認有撐就買，次日跌破月線就被套）。
### 接近壓力時的 K 線判斷
1. 遇壓當天大量中長紅 → 多方仍強，次日要過壓；次日收下跌黑K → 「關前爆大量，股價不漲要回檔」。
2. 遇壓當天大量長上影或中長黑（盤中過壓收盤沒過）→ 賣壓出現，次日易跌。
3. 遇壓當天大量變盤線 → 看次日，收黑 → 確認遇壓回檔。
4. 遇壓當天大量中長紅突破 → 注意次日大量長黑 → 假突破機率高，多單備停損。
### 接近支撐（鏡像）
1. 遇撐當天大量中長黑 → 次日收紅 =「遇撐爆大量，股價不跌要反彈」。
2. 大量長下影或中長紅（盤中破、收盤未破）→ 次日易反彈。
3. 大量變盤線 → 看次日，收紅=確認有撐。
4. 大量中長黑跌破 → 次日大量長紅 = 假跌破，空單備停損。
### ★ 進出位置
- 多頭買點：回檔遇到 ①月線/季線 ②上升切線 ③前低 ④下方大量跳空缺口 的支撐，出現止跌紅K或長下影 → 準備次日上漲的買點。
- 空頭空點：反彈遇到 ①月線/季線 ②下降切線 ③前高 ④上方大量跳空缺口 的壓力，出現止漲黑K或長上影 → 次日下跌的空點。
### 慣性變化
- 多頭沿 MA10 上漲、回檔不破 MA10 → 強勢多頭。
- 回檔不破前低、在上揚月線之上 → 多頭不變。
- 突破前高 → 多頭不變；未過前高下跌 → 盤整。
- 回檔跌破前低 → 趨勢改變，反彈不過前高 = 多單逃命波。
- 跌破月線 → 轉弱；3~5 日內無法站回，月線易下彎成壓力。
- 空頭鏡像（沿 MA10 下跌、反彈不過 MA10 = 弱勢空頭…）。

## 6-2 走勢圖中的支撐壓力位置
- 轉折高點（頭）：突破後回檔遇頭有支撐；股價在頭下方時頭為壓力（解套賣壓）。頭處有大量/爆天量 → 壓力更強。
- 轉折低點（底）：股價在底上方時為支撐；跌破後底變壓力。
- 密集盤整區：股價在上方 → 整區為支撐；股價在下方 → 整區為壓力（反彈到下沿壓力最強）。突破上沿 → 盤整區轉為支撐；跌破下沿 → 轉為壓力。
- 盤整區上下頸線：上頸線=壓力、下頸線=支撐；大量突破上頸線 → 做多。
- 空轉多：空頭頭部 2 高點常有大量（套牢壓力）；打底大量（進貨支撐）；突破空頭高點壓力 → 後勢易大漲（突破做多）；之後高檔大量價量背離 / 強覆蓋要注意。
- 多轉空（鏡像）：多頭底部大量=支撐；盤頭大量=壓力；跌破底部支撐 → 易大跌一波，做空好機會。
- 上升切線=支撐；下降切線=壓力；突破後轉換。
- 均線支撐壓力：上揚均線=支撐，下彎=壓力；MA20 > MA10 > MA5 力道；同週期角度越大越強；強壓力均線被突破 → 多方更強易快速上漲。多頭回檔跌破月線後再站上月線 → 繼續做多。空頭反彈突破月線 → 空方力道減弱；突破後 3 日內再跌破且月線仍下彎 → 仍可做空。
- 跳空缺口：向上跳空缺口（大量）有支撐，支撐是整個缺口；缺口被跌破回補 → 空方轉強，之後反彈到該處也無壓力作用（詳 Part09）。向下跳空缺口=壓力；被突破回補 → 多方轉強。
- 大量中長紅 K：最高點/1/2/最低點支撐（同 Part03）；大量中長黑 K：最低點壓力最強，1/2 為平均成本壓力，突破 1/2 上漲轉強，突破最高點空多易位（做空者停損回補），被突破後變支撐。

## 6-3 看不見的支撐壓力
- 黃金分割：0.236、0.382、0.5、0.618、0.809 位置（多頭回檔支撐 / 空頭反彈壓力）。
- 型態目標價（等幅測量：頸線到底/頂的距離往突破方向投射）：
  - 底部 4 型（空頭底部反轉成功率高）：頭肩底、圓弧底、N 字底、三重底；大量突破頸線=突破確認買點；目標價=壓力。
  - 頂部 4 型：頭肩頂、圓弧頂、倒 N 字頂、三重頂；大量跌破頸線=做空點；目標價=支撐。
- 整數心理關卡（例：台積電 900 元、大盤 24,000 點）→ 常出現震盪。
