# Part08 指標篇 — 規則筆記

## 8-1 MACD
- 計算：DIF = EMA12 − EMA26（書中寫 MA12−MA26）；MACD(signal) = DIF 的 9 日平均；OSC = DIF − MACD（紅柱 > 0、綠柱 < 0）。書中範例也用 DIF10-20 / MACD10。
- 多頭：2 線在 0 軸上，DIF 上穿 MACD 黃金交叉 = 買訊再上漲；死亡交叉 = 多頭高檔可獲利賣出，拉回 0 軸不破 = 多頭回檔。
- 空頭：2 線在 0 軸下，黃金交叉 = 空頭低檔空單回補（反彈到 0 軸不破才可再空）；死亡交叉 = 空頭賣訊再跌。
- OSC 柱狀（多頭）：紅柱縮短=回檔；紅柱漸長=續抱；紅柱漸長但價不漲/下跌=動能背離準備賣；紅柱由縮短轉增長=漲勢再起回後買上漲；綠柱縮短接近 0 軸後轉紅=易再漲；紅柱縮短接近 0 軸轉綠=易續回檔；股價創新高（1~3 次）紅柱未創新高=高檔背離，做頭機率大。
- 空頭鏡像：綠柱縮短=反彈；綠柱漸長=續抱空；股價創新低綠柱未創新低=低檔背離，打底機率大。
- 背離 2 種：
  1. **波段背離**：股價上漲但紅柱縮短 → 易回檔；股價下跌但綠柱縮短 → 易反彈。
  2. **趨勢背離**：股價頭頭高但兩波紅柱群頭頭低 → 易轉空頭；股價底底低但兩波綠柱群底底高 → 易轉多頭。

## 8-2 KD
- RSV/K/D：K = 100×(C−L_n)/(H_n−L_n) 平滑；常用 9 日（書中 KD(9,3)），短線可用 5 日 KD(5,3)。
- 交叉解讀依趨勢：多頭 → 黃金交叉買點、死亡交叉多單賣點；空頭 → 死亡交叉空點、黃金交叉回補；**盤整 → 交叉都不進場**。
- 週期：短線看日 KD、中期看週 KD、長期看月 KD。
- 鈍化：K/D ≥ 80 盤整=高檔鈍化；≤ 20=低檔鈍化；此時 KD 失去參考價值，回歸看價量。
- **KD 背離**：股價頭頭高但 K 線頭頭低 = 高檔背離（反轉先期訊號，股價也頭頭低時即將轉空）；股價底底低但 K 底底高 = 低檔背離。
- KD 背離重點：峰背離（價頭頭高、K 頭頭低）、底背離（價底底低、K 底底高）；背離表示可能反轉，尤其底背離要注意隨時反彈；**指標背離要在 20~80 之間才正常有效**。

## 8-3 RSI
- RSI = N 日平均漲幅 / (平均漲幅 + 平均跌幅) × 100。常用 6 日、12 日。
- 逆勢指標：> 80 超買易跌；< 20 超賣易漲。RSI6 上穿 RSI12 黃金交叉=多頭買進參考；死亡交叉=空頭做空參考。
- 高檔背離（價創高 RSI 未創高）→ 注意頭頭低易反轉；低檔背離同理。
- 盤整區不宜用 RSI；強勢連續急漲/急跌時 RSI 易失真。

## 8-4 乖離率與 MA 通道
- 乖離率 = (收盤 − MA_N)/MA_N × 100，常用 N=20。正乖離過大=超買有回跌壓力；負乖離過大=超賣有反彈動能。
- 乖離過大時避免追高殺低，等回檔修正後再看是否符合進場條件；可做急漲後短空或急跌後短多（逆勢）。緩漲/盤整股乖離無效。
- **MA 通道**：MA20 上下 ±12%~15%（範例 ±15%）。價格常在通道內；觸及上軌=正乖離壓力，觸及下軌=負乖離支撐；連續急漲正乖離過大+連續大量+長上影變盤線 → 回檔。帶量突破軌道線=趨勢轉強。

## 8-5 布林通道 BBands(20, 2σ)
- 上軌=MA20+2σ（壓力）；中軌=MA20；下軌=MA20−2σ（支撐）。超出軌道機率約 4.6%。
- 4 買訊：①空頭低檔由下向上穿越下軌（搶反彈）②多頭回檔跌破中軌後再站上中軌 ③價在中軌與上軌間向上=多頭續抱 ④3 軌平行時股價突破盤整做多。
- 4 空訊：①由上往下穿越上軌（搶多頭回檔）②在中上軌間跌破中軌（空頭反彈突破中軌後再下中軌）③價在中下軌間=空頭續空 ④3 軌平行時跌破盤整做空。
- ★ 進階（趨勢+布林+MA5+K線）：
  1. 多頭上漲上軌由平走揚張口、K 線沿上軌上漲 → 持股續抱，直到黑K跌破 MA5 才停利。
  2. 多頭不變，上中軌向上、股價在上軌之上 → 多頭持續。
  3. 上軌上揚後走平或下彎 → 進入盤整或急速回檔；回檔跌破中軌易觸及下軌。
  4. 開口收斂橫盤，3 軌近水平；大量紅K突破盤整 → 喇叭開口，沿上軌加速上漲 → 進場做多。
  5. 鏡像：大量黑K跌破盤整 → 沿下軌加速下跌 → 做空。
  6. 上中下軌同時向上 → 強勢，短期續漲；7. 同時向下 → 弱勢續跌。
  8. 上軌向上而中下軌向下的可能性很小。
  9. 上軌向下、中下軌向上（通道縮小）→ 回檔/整理：長期上升趨勢中=強勢整理，可持股或逢低短買；長期下跌=弱勢整理，持空或反彈做空。
  10. 3 軌皆水平 → 退出觀望等突破。
  11. 仍以波浪趨勢方向、個人紀律為主軸，布林為輔。
