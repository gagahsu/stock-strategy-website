# Part04 均線篇 — 規則筆記

## 4-1 基本
- MA = N 日收盤平均（平均成本）。收盤 > MA5 → 5 日內買的人平均賺錢。
- 策略對應：長期=10週/20週；中期=MA20/MA60；短期=MA3/5/10；當沖=1/5/15/60 分。
- 缺點：長期均線慢；盤整時均線糾結無法判斷。

## 4-2 移動扣抵（可程式化：預知均線方向）
- 扣價 = N 天前（將被扣除）那天的收盤；抵價 = 今日收盤。
- 今收 > 扣價 → MA 上彎；< → 下彎；= → 走平。
- 應用：
  - 預知明日 MA 方向：明日收盤只要大於明日扣價，均線就上彎。
  - 「扣抵區間」：未來 N 天的扣價序列 vs 現價 → 推算幾天後 MA20 可能翻揚、MA10 何時上穿 MA20（多頭排列）。
  - 範例做多條件：趨勢頭頭高底底高 + MA10 > MA20 多排 + 兩條均線方向向上。指數範例：多頭確認但月線向下 → 不符做多；次日收盤 > 扣價月線翻上 → 做多買進。
- 空轉多底部必經盤整：等股價站上均線且均線走平/上彎；MA20 從下彎轉上彎 = 完成多頭底部。
- 均線上彎 3 大作用：①支撐 ②助漲（跌破但均線仍上彎，易再站回）③減弱黑K下殺力道。
- 均線下彎 3 大作用：①壓力 ②助跌 ③減弱反彈紅K力道。
- 強度：天期越長越強（MA20 > MA10 > MA5）；同天期上彎角度越大越強，改變方向時間越久。

## 均線多頭/空頭排列
- 多頭排列：短在上長在下（MA5>MA10>MA20>MA60>MA120>MA240），方向皆向上。6 線多排（5/10/20/60/120/240）→ 可鎖股中長多。
- ★ 短多日線條件：①頭頭高底底高 ②至少 3 線（5/10/20）多排且方向都向上 ③收盤站上 MA20。打底完成但 3 線未多排或季線下彎壓力未化解 → 易再拉回/盤整，盡量等 3 線或 4 線多排。
- 週線中長多：5週/10週/20週 3 線多排。週線 3 線空排 → 可長期做空。
- ★ 短空：頭頭低底底低 + 3 線空排向下 + 收盤跌破 MA20。季線仍上彎 → 尚有支撐，等 3/4 線空排。
- 盤整：均線交錯糾結 → 不介入，等排列完成。

## 黃金交叉 / 死亡交叉
- 黃金交叉：短均線向上穿越長均線（如 MA10 上穿 MA20）。死亡交叉相反。
- 短線常用 MA5/MA10 交叉。須配合趨勢：多頭中黃金交叉=回檔結束買點參考，死亡交叉=獲利賣出參考；空頭中死亡交叉=反彈結束做空參考，黃金交叉=回補參考。不可單憑交叉就做多/空。

## ★ 均線糾結（飆股起漲選股法，可程式化）
- 狹幅盤整 5~6 天 MA5 走平；10~12 天 MA10 走平；更久 MA20 走平 → 5/10/20 糾結；更久季線也糾結。越多條、越久糾結 → 發動力量越大。6 線（5/10/20/60/120/240）糾結發動要把握。
- 口訣：突破均線糾結的向上紅K = 起漲開始；跌破均線糾結的向下黑K = 起跌開始。
- 做多操作：
  1. 每天收盤後看強勢股；放量突破均線糾結的中長紅K → 準備明天進場。
  2. 開始發動後第 2、3 天若沒大漲都還可進場。
  3. 起漲第 2 天就飆漲停 → 不追，等第 1 段飆漲後回檔再漲切入（飆股多有 2 段飆漲期）。
  4. 停損：進場 K 最低點；若進場為小紅K則以 -5% 停損。
  5. 用「智慧K線交易法」：收盤未跌破前一日 K 低點續抱。
  6. 每天 13:20 看盤，確認收盤會跌破前一天 K 低點 → 掛市價賣出。
  7. 賣出後若仍多頭，再出現紅K收盤突破前一天高點 → 再進場，重覆 4~6。
  8. 上漲一段再盤整糾結 → 再次突破做多。
- 範例：均線糾結突破 → 4 線多排；高檔長黑吞噬多單賣出；跌破 5 均多單賣出；第 2/3/4 波買進；高檔大量長黑。
- 做空鏡像：弱勢股中長黑跌破均線糾結 → 準備明天放空。

## ★ 葛蘭碧 8 大法則（走勢 + MA20，可程式化）
做多買點：
1. **買①（反轉）**：MA20 由下降轉平緩/上揚，股價由下往上突破 MA20（大量長紅突破 MA20、當天 MA20 開始上揚）。
2. **買②（回測支撐）**：股價在 MA20 上、MA20 上揚，回檔到 MA20 附近轉而上漲（紅K）。在 MA20 支撐上橫盤，大量紅K突破盤整也是買點。
3. **買③（假跌破）**：MA20 保持上揚，股價回檔跌破 MA20 但很快以大量紅K站回 MA20。
4. **買④（負乖離過大搶反彈，逆勢短線）**：空頭急跌連 3 天以上，與 MA20 乖離 > 15%（範例設 ±15% 乖離通道），低檔大量後紅K突破前一日高 → 搶反彈；黑K跌破前一日低 → 停利。
做空賣點（鏡像）：
5. **賣①**：MA20 由上升轉平/下彎，股價由上往下跌破 MA20（長黑跌破 MA20 + 跌破前低=空頭確認）。
6. **賣②**：股價在 MA20 下、MA20 下彎，反彈到 MA20（或 MA10）附近轉而下跌。
7. **賣③**：MA20 下彎，反彈突破 MA20（大量長紅）但很快再跌破 → 做空訊號。
8. **賣④（正乖離過大）**：多頭連續急漲與 MA20 乖離 > 15%，高檔連 3 日爆大量 + 十字變盤線 → 次日黑K下跌做空。
- 範例常見：高檔爆大量長紅後要注意不漲會跌；長黑吞噬 → 回檔。

## 4-3 ★ 均線戰法（可直接做成回測策略）
### A. MA5 短線做多
- 前提：多頭不變、股價在 MA20 上、MA10/MA20 多排。
- 進場：①回後買上漲（收盤突破 MA5 且突破前日高）②盤整突破（含 K 線橫盤突破）③急跌反彈確認 ④底部型態確認。
- 停損：進場紅K漲幅 < 5% → 守上漲轉折最低點；進場紅K低點距離 > 5% → 守進場紅K最低點。
- 出場：進場算 +10% 價位；漲超過 10% → 收盤跌破 MA5 停利；未到 10% → 跌破 MA5 續抱；盤整出場（未過前高頭頭低、收盤破 MA5、收盤破前日低）；急漲 3 天以上中長紅K或獲利 ≥20% 後出現高檔爆量長黑（開高走低 >5%）或爆量長上影 → 當日停利一半，次日下跌全出；長黑吞噬 → 當天全出。
- 範例：立積 6 趟 +96.8%；台光電 4 趟 +10.39%。
### B. MA5 短線做空（鏡像），範例禾伸堂 2 趟 +11.07%。
### C. MA10 中線做多/做空：同上但改守 MA10（範例台光電 3 趟 +24.4%；上銀做空 6 趟 +28%；東浦 +23.4%）。
### D. 單一均線長線做多（MA20 進出、MA60 判斷長期方向）
- 站上 MA20 且在 MA60 上 → 買多；跌破 MA20 但在 MA60 上 → 賣出觀望。
- 選股條件（日+週+月）：日線多頭確認，MA10/20/60 多排向上；週線多頭確認，MA10/MA20 多排向上；月線大量突破下降切線。
- 進場：底部多頭確認 4 線多排，股價在 MA20 上，第 1 次回測不破 MA20，股價突破 MA5 及昨高開始進場。
- 程序：日線先做短線；上漲一波 4 線多排獲利後改守 MA20；波段獲利 >20% 且與 MA20 乖離 >20% → 收盤破 MA10 停利；日線高檔爆量空頭確認先出場；末升段或已漲近 1 倍 → 只做短線守 MA5。
### E. 2 條均線（MA10、MA20 定多空）
- MA10/MA20 黃金交叉多排向上 → 開始做多；死亡交叉空排向下 → 做多結束。獲利 >20% 收盤破 MA5 停利。
### F. ★ 3 條均線綜合戰法（分批 3 等分）
- MA5 短多、MA10 中多、MA20 長多；底部多頭確認、4 線多排向上開始做多，一次買 3 的倍數張。
- 收盤跌破 MA5 賣 1/3；跌破 MA10 再賣 1/3；跌破 MA20 賣最後 1/3。
- 多頭不變：收盤突破 MA5 買回 1/3；突破 MA10 再買 1/3；突破 MA20 再買 1/3（站上 MA5 時恢復滿倉）。
- 波段獲利 >20% 收盤破 MA5 全部停利；末升段或漲近 1 倍 → 只做短線守 MA5。
- 做空鏡像；末跌段或已跌近頭部起跌 1/2 → 只做短空。
