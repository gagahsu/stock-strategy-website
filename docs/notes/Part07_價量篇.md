# Part07 價量篇 — 規則筆記

## 7-1 觀念
- 量價非絕對因果；需結合 趨勢方向、位置（起漲/起跌/行進中/突破/跌破/壓力下沿/支撐上沿）、股價漲跌（當天或次日）、量增減幅度 一起判讀。股價才是重心。
- 多頭起漲紅K：量增會漲，量縮也會漲。

## 7-2 ★ 成交量定義（可程式化，基準=5日均量）
1. **基本量** = 5 日均量（MA5 volume）。
2. **攻擊量** = 基本量 1.2~1.3 倍且股價上漲（常見於多頭起漲）。
3. **爆大量** = 基本量 2 倍以上；起漲位置=攻擊量；多頭高檔/遇壓位置易是出貨量，注意後面幾天是否下跌。
4. **止跌量** = 股價下跌時量急縮到 5 日均量一半，且後續不再破低。
5. **進貨量** = 攻擊量或爆大量 + 股價上漲。
6. **換手量** = 高檔出現大量 K，3 日內股價突破該大量 K 最高點 → 強勢續漲（飆股常見，換手成功多再急漲一波）。
7. **出貨量** = 攻擊量或爆大量但股價下跌或趨勢反轉。
8. **調節量** = 高檔大量 K 後下跌修正，之後上漲突破該大量 K 高點 → 該量為主力洗盤調節量。
9. **搶反彈量** = 空頭連續下跌到低檔出現大量，後續不跌出現紅K突破前一日高點 → 反彈。
- 範例：連續上漲高檔爆大量，次日下跌=出貨/調節量；次日上漲=換手量；多頭回後買上漲大量紅K=攻擊量。

## 7-3 不同趨勢位置的量價
### 多頭上漲高檔爆量（漲 3~4 天後出現爆量 > 前日 1 倍）→ 判斷 3 種
- **調節量**：①回檔價跌量急縮 ②接近重要支撐（月線、前低、向上跳空缺口、大量上漲紅K）出現止跌K（變盤線/中長紅）③未跌破前低、未跌破月線又上漲。→ 常見於初升/主升段。
- **換手量**：大量下跌後次日小跌或不跌，接著突破大量下跌黑K最高點 → 續漲（飆股常見，換手成功後多急漲一波）。
- **出貨量**：末升段高檔盤整的大量，大量盤整被跌破 → 空頭確認；飆股高檔爆量後 1 日反轉快速下跌也是出貨量。
### 多頭上漲量價背離（3 種）
1. **價漲量縮**：高檔創高但量縮，追價力道弱，出現黑K下跌 → 漲多要回檔（KD/MACD 背離同理）。
2. **價平量增**：量增但價不漲 = 停滯；底部價平量增 = 主力進貨；高檔價平量增 = 主力出貨（利多不漲）。
3. **價漲量平**：量能停滯，上漲有限 = 止漲徵兆；漲幅大或接近壓力時若不能及時量增易反轉。
### 多頭起漲的成交量
1. 起漲大量後續上漲 → 攻擊量（或高檔調節後再買回）。
2. 次日下跌，**起漲大量紅K最低點不能跌破**，否則為誘多出貨量（高檔/末升段常見）。
3. 起漲紅K沒放大量、次日補量上漲 → 續漲。
4. 大量起漲後下跌數天未破起漲紅K最低點，再放量上攻 → 前面下跌為洗盤。
5. 大量紅K突破盤整起漲，次日大量黑K跌破起漲紅K最低點 → 假突破，兩根大量=出貨量。
### 底部打底的成交量（第 1/2 支腳）
- 見 Part02 同章節：第 1 腳爆量=搶反彈進貨量；反彈到 MA20 遇壓黑K → 續空，但跌不破第 1 腳出現底底高要回補；反彈突破月線+前高 → 再跌易出底底高第 2 腳（黃金右腳）；MA10/20 多排 → 鎖股短多；突破 MA60 4 線多排 → 中長多。
### ★ 多頭高檔量的變化（停利規則）
1. 高檔異常天量（前一日量 2~5 倍以上）後出現長黑K下跌 → 易 1 日反轉，飆股常見，立刻停利。
2. 上漲時連續 2~3 天爆大量（5 日均量 2 倍以上）後股價不漲或下跌 → 立刻停利；末升段做頭機率高。
### 空頭
- 空頭確認的爆大量：高檔頭頭低底底低，大量長黑確認 → 多單立刻賣；已跌破月線且月線下彎、未破季線 → 可短空；未破月線 → 等彈後空。
- 空頭下跌中大量長黑：次日易續跌；該黑K高點=壓力、低點=支撐 → 高點被突破=反彈確認，低點被跌破=換手失敗續跌。之後反彈結束再跌但不破底（底底高第 2 腳）→ 第 1 腳大量為主力進貨量。
- **窒息量/凹洞量**：大量長黑次日續跌但量縮到大量的 1/2 以下 = 窒息量；次日若出大量紅K反彈 → 易強力反彈（3 天晨星）。
### ★ K 線量價綜合總結
1. 紅K量=當日買方追買量；2. 黑K量=賣方追賣量。
3. 多頭大成交量後上漲突破 → 攻擊進貨量，日後支撐；4. 多頭大量後下跌跌破 → 出貨量，日後壓力。
5. 空頭大量後上漲突破 → 搶反彈進貨量（支撐）；6. 空頭大量後下跌跌破 → 恐慌出貨量（壓力）。
7. 盤整區大量 = 換手累積量；向上突破=換手成功（支撐），向下跌破=換手失敗（壓力）。
8. 多頭轉折：①起漲大量紅K後上漲，最低點是關鍵點，被跌破停損；②起漲大量紅K次日大量黑K → 2 根 K 的高低點是關鍵，突破黑K高點續漲（黑K為洗盤），跌破紅K低點停損（紅K為誘多）；③高檔大量紅K最低點是關鍵，跌破則回檔；高檔大量黑K次日開低走低或開高走低 → 回檔；④高檔連續急漲暴大量（末升段）只能漲不能跌，出現黑K易急跌反轉；⑤高檔創新高量遞減 = 量價背離，出現黑K不漲易回檔盤頭。
9. 空頭轉折（鏡像）：起跌大量黑K最高點是關鍵（被突破停損）；低檔連續急跌暴大量出現紅K易急漲反轉；低檔創新低量遞增=量價背離，出現紅K不跌易反彈打底。
10. 上漲遇壓大量紅K收盤未突破，次日黑K不漲 → 回檔。
