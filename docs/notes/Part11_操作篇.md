# Part11 操作篇 — 規則筆記

## 11-1 進場前的準備工作
### ★ 技術分析選股 8 種進場位置（全部可程式化為 entry rule）
1. **等打底完成**：空頭低檔大量盤整打底 → 鎖股；打底盤整突破、反轉多頭確認，同時站上月線且月線向上，大量紅K突破盤整 → 做短多；同時站上季線 → 可做長多。
2. **等突破盤整**：多頭上漲一波後盤整，大量紅K突破盤整 → 做多。
3. **等拉回**：多頭連續上漲高檔，拉回不破前低、不破月線，再上漲 → 做多。
4. **等上漲（回後買上漲）**：多頭上漲一波後回檔，不破前低、不破 MA20，上漲時做多。
5. **等 K 線橫盤突破**：多頭中 ≥3 天 K 線橫盤 → 鎖股；大量紅K突破橫盤 → 做多。
6. **等 ABC 突破**：多頭上漲一波後 A-B-C 3 波修正（形成短空），反彈大量紅K突破下降切線，股價在 MA20 之上 → 做多。
7. **等型態確認**：空頭低檔打底型態（頭肩底、W底…），型態確認上漲大量紅K → 做多。
8. **等突破大量黑K**：多頭上漲一波後大量黑K跌破前日低點或跌破 MA5，隨即（3 日內）大量紅K突破該大量黑K最高點 → 做多。

### 進場後走勢推演
1. 停損（可能最大賠損）：買進當天就設好，跌破當天執行（可固定 5%）。
2. 獲利目標：短期=日線向上第 1 個壓力；中長期=週線向上第 1 個壓力。
3. 上漲未過前高（頭頭低）→ 趨勢進入盤整：短線暫時出場，等盤整確認突破再進；長線續抱，盤整跌破出場。
4. 上漲突破前高（頭頭高）→ 多頭不變，依 SOP 停利。
5. 上漲遇壓力：突破續抱，遇壓下跌依 SOP 停利。

### ★ 停損
- 原則：擬定策略時先設停損點；設好不得更改；收盤跌破立即出場；以順勢為主在高勝率位置進場減少停損次數；**停損不超過 10%**。
- 5 種設法：
  1. **K線停損**：做多=進場K最低點；做空=進場K最高點。
  2. **趨勢停損**：回後買上漲→轉折波低點；盤整突破→突破點（頸線）；做空鏡像。
  3. **均線停損**：以進出依據的均線為停損（例：上 MA5 買進，停損=進場時 MA5 值）。
  4. **固定比例停損**：買進價 2%~10%，一般固定 5%。
  5. **支阻停損**：關鍵支撐跌破停損（頸線、缺口）；做空時關鍵壓力突破停損。
- **絕對停損**：①盤整區布局多單，跌破盤整區 ②多頭高檔趨勢反轉、空頭確認 ③空頭低檔反轉、多頭確認（空單）④跌幅超過 10% ⑤逆勢單反轉。
### 上漲預測獲利目標
- 短線先以最近壓力為初步目標；壓力 = 前高、長週期下彎均線、大量黑K、向下跳空缺口、盤整區（日線看短、週線看中長）。
- 見壓不是壓：到壓力看 K 線轉折訊號 + 個人紀律（守 MA5）；也可依到壓力時是否達目標、或與月線乖離太大決定出場。
- 日線短線獲利出場後多頭沒變可繼續做；走勢符合中長期條件可改中長期操作。
- 上漲未過前高：①進入盤整→短線出、長線抱 ②反轉空頭→長線出 ③盤整後續多→短多再進場。
- 上漲突破前高：①多頭不變 ②短線準備停利，破 MA5 出 ③拉回鎖股做多。
- 遇日線壓力：突破續抱，遇壓下跌破 MA5 出場；遇週線壓力：看日線依 SOP。

### ★ 投入資金分配原則（→ 部位管理 / 回測資金模型）
- 規劃：投入資金 ≤ 可運用資金 1/2；不可借貸；最多投入 9 成（不滿倉）；獲利時收回部分當準備金。
- **隨大盤（加權指數）走勢調整資金比例**（圖 11-1-16，可程式化成「大盤水位表」）：
  | 大盤狀態 | 投入資金 |
  |---|---|
  | 多頭頭頭低（警訊） | 5 成 |
  | 空頭確認 | 4 成 |
  | 4 線空排 / 中期空頭（跌破 MA60） | 3 成 |
  | 長期空頭 / 跌破上升切線 | 2 成 |
  | 空頭轉多頭確認 | 3 成 |
  | 4 線多排前（站上 MA20/MA60 初期） | 4~5 成 |
  | 4 線多排、中長多頭 | 6~8 成 |
  | 末升段 | 5 成 |
- 例：2022/1/21 空頭確認 4 成 → 3/7 中期空頭 3 成 → 4/11 長期空頭 2 成 → 6/13 跌破切線 2 成；2022/11/7 多頭確認 3 成；2023/5/17 多頭確認 3 成 → 5/25 中期多頭 6~8 成 → 6/27 跌破月線 4 成 → 7/6 空頭確認 3 成 → 8/10 空頭確認 2 成。

## 11-2 ★ 進場實戰操作 SOP
### 短線波段操作守則（20 條）
1. 進場 K 條件：收盤突破 MA5、突破前一日高點、紅K實體漲幅 ≥2%、MA20 向上、KD 值向上、量增或量平。
2. 停損=進場價 5%，收盤跌破出場。
3. 收盤出現頭頭低 → 出場。
4. 沒跌破停損續抱。
5. 漲幅 < 10% 跌破 MA5 → 續抱。
6. 漲幅 > 10% 收盤跌破 MA5 → 停利。
7. 獲利 > 20%、或連 3 天以上長紅、或連續急漲，出現大量長黑但未跌破前日低 → 減碼 1/2，次日開低向下全出。
8. 獲利 > 20%，當日大量長黑收盤跌破前一日 K 低點 → 全部出場。
9. 大量紅K收盤突破 MA5 但 KD 值向下 → 待 K 值向上再買。
10. 進場紅K上影線 > 1/2（實體?）→ 不買，看次日。
11. 遇壓黑K跌破前日紅K 1/2（強覆蓋）+ K 值下彎 → 先賣 1/2。
12. 高檔爆量長上影為壓力，下跌再上漲時，進場點距該高點 < 5% → 等突破上影線高點再買。
13. 下跌再上漲，進場點距高點壓力達 10%、未破月線 → 仍可回後買上漲；上漲未過高點出現大量黑K → 立刻出場。
14. 高檔連 2 日爆量、回檔連 3 黑 → 「回後買上漲」點不進。
15. 做多時黑K跌破 MA5 但跌幅 < 1%、量縮、MA20 向上 → 當日可續抱，次日下跌賣出。
16. 遇 K 線橫盤：跌破 MA5 續抱，跌破 K 線橫盤時賣出。
17. 低檔（初升、主升）起漲進場後遇橫盤（漲幅 5% 內）或下跌未到停損，再放量紅K上漲 → 可加碼，加碼單另設停損停利。
18. 短波段漲幅已達 10% 以上 → 不宜加碼。
19. 週線接近壓力，日線黑K跌破 MA5 → 多單先出。
20. 底部反轉做多，上漲突破季線但季線向下，回檔跌破 MA5 → 即使漲幅未達 10% 多單先出。
### 長線波段操作守則
- 選股：月線大量中長紅K突破下降切線、反彈站上 MA20；週線多頭 3 線多排、底部放大量；日線多頭 4 線多排、底部多頭確認後起漲。
- SOP（MA20 + 週線）：日線多頭進場（同短線第 1 條）；停損 5%；頭頭低出場；未破停損續抱；**漲幅 > 10% 收盤跌破 MA20 停利**；一波獲利 > 20% 連 3 長紅/連續急漲後大量長黑跌破前日低出場；出場後由起漲算漲幅 < 50% 且符合日線條件 → 可再進場做第 2 波；**股價上漲約 1 倍後不做長線**。
### ★ 飆股交易實戰守則
- 如何選飆股：①曾有飆漲紀錄者優先 ②中小型股 ③長期盤整(≥2 個月)、左低右高(≥2 支腳)、過頸線發動、回測頸線再發動、第 1 段飆漲短期整理再發動 ④雙重底大量突破 + 4 線多排 ⑤均線糾結大量紅K上漲 ⑥大量紅K突破長期下降切線、站上月線後盤整再大量突破 ⑦發動點需配合擴大成交量 ⑧每天過目強勢股，符合者列入鎖股。
- 飆股續抱條件（完全依技術面）：未破上升趨勢線、**未破前 2 日低價、未破 3 日均線**、未出現黑K → 續抱。
- 成交量研判：無量飆漲續抱；量稍放大價穩續抱；量放大價大幅震盪先出一半；量大增價仍收紅 → 保守者先出或再看次日；量大增、開高走低出黑K、高點已到 → 迅速賣出。
- 飆股 3 種變化：起飆拉回再飆、長黑K洗盤再飆、續勢整理(三角收斂)再飆。**80% 飆股有 2 波上漲，10% 有 3 波，10% 只有 1 波**。
- 範例旺矽 6223：多頭確認季線向下做短多 → 空頭確認 → ABC 修正突破進場 → 第 1 波 → 停利 → 回後買上漲 → 第 2 波 → 頭頭低盤整 → 盤整突破 → 第 3 波 → 停利。

## 11-3 ★ 12 個操作口訣（→ 可做成「口訣偵測器」警示/訊號）
| # | 口訣 | 程式化方向 |
|---|---|---|
| 1 | 多頭大量不漲，股價要回檔（當日或後數日） | 多頭中量 ≥2×5日均量，但收盤漲幅 ≤ 0 或長上影 → 回檔警示 |
| 2 | 空頭大量不跌，股價要反彈 | 空頭中大量但收盤不跌/長下影 → 反彈訊號（之後多頭確認） |
