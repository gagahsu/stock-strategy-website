# 規則精度與原圖核對

所有進場、警示與出場判斷只使用訊號日及以前的完成日K。MA 正負價群的轉折包含穿越當日，轉折只在穿越日確認，不回填到轉折發生日期。

## 可直接計算

均線排列與扣抵、紅黑實體、昨量比與前5日均量比、MACD、KD、RSI、乖離、布林、真／隱形缺口、進場K停損、固定比例停損、K線戰法與均線停利。

## 第一版明列近似

底部／高檔位置使用60日高低與120日波段漲幅；盤整使用前10日箱型；大量預設前5日均量1.3倍；爆量2倍；切線、ABC、軌道、雙底與雙頭以已確認转折與突破位置近似。新聞題材、分時、人工判讀與無法確定的法人連賣項顯示未知，不假設通過。

33種圖像都有個別規則ID與數值近似標示；其中雙弧底暫以雙底代理，不能宣稱辨識圓弧曲率。圖像訊號作研究候選，不代表已完成33種形態的逐圖黃金驗收。

已閱讀12-4全部42頁縮圖，核對33圖的註記；其中「突破大量黑K」、「突破2日大量高點」、「低檔長下影」與「月線上整理突破」的買點應在突破／次日確認，不能在先前的爆量或長下影當日保證反轉。原圖上顯示日期與圖內時間軸可能不同，以圖上箭頭與時間軸為主，不能直接把畫面日期當訊號日。

## 驗證

`tests/test_engine.py` 驗證特徵前綴不變、訊號前綴不變、次日成交、不得當沖、成本扣除、跳空較差成交、可調最大虧損與未驗證還原價拒絕回測。

`scripts.verify_live` 使用實際載入的台積電／鴻海／聯發科資料做整合檢查，產出本機 `data/verification.json`。

書中全部示例圖的逐圖比對與形態精度量測尚須更多原圖日期標註，不能用單元測試通過代替。

### 漢磊3707 MA5實例

已逐價核對2-5-29（Part1_0067.png）：2019/06/12、06/26、07/10、07/16、07/23、07/30、08/16、08/26、08/28、09/09、09/17、09/25，共6次進出、12個收盤價。`tests/test_book.py` 使用公開行情凍結樣本驗證價格及MA5條件；首筆為大量紅K突破，最後一筆含量縮小幅跌破MA5的隔日處理。書中簡化算式為7.6元／45.6%；精確價差為7.65元／45.9%，差異來自中間數字取位。網站次日開盤成交模型不把書中當日收盤績效當作自己的績效。

### SOP與資料限制

短線20條中，主觀壓力與上影線比例需依原圖人工確認；週線壓力以此前已完成12週高低／20週均價及3%距離近似，當週尚未發生的高低不回填。加碼提示與個別持股批次可記錄，回測除三均線補回外不自動執行新的加碼單。這些限制不得宣稱為全部SOP精確自動化。

### 華夏1305缺口四價位

9-4-6（Part3_0148.png）的圖內時間軸是2012年，表頭2013/07/24不適合作為訊號日期。公開日K重現2012/09/17的上高14.75、上沿14.10、下沿13.80、下底13.20，以及09/18、09/20、09/25、10/04依序跌破的收盤價；09/25一般黑K為假封口，10/04大量長黑K才升級真封口。`tests/fixtures/book_gap_1305.json`保留公開行情，`tests/test_book.py`按每個當時資料前綴驗證，沒有提前引用10/04的成交量。此測試核對缺口語意，未用原始價格當作含股利的投資績效。

淘汰法可計算項預設納入API回測，人工與未公布籌碼維持未知；已知不通過會拒絕進場，介面可關閉此濾網以比较。股票池日均量及每日檢查固定採日K，切換週月圖只改變圖表與該週期的訊號。
