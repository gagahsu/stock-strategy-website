# 技術分析策略網站 — 規劃書

> 依據：Part02 趨勢 ~ Part12 財富（規則萃取於 `notes/PartXX_*.md`）
> 決策：台股上市櫃｜免費資料｜多空都做｜Python 引擎 + Next.js 前端
> 功能：每日選股掃描、個股診斷、策略回測、持股追蹤與出場提醒

---

## 1. 系統架構

```
┌──────────── 資料層 ────────────┐   ┌──────── 運算層 (Python) ────────┐   ┌──── 呈現層 (Next.js) ────┐
│ TWSE/TPEx OpenAPI (每日全市場) │──▶│ ingest  → 日K / 除權息 / 融資券 │   │ /scan     今日掃描       │
│ FinMind 免費 (歷史/營收/法人)  │   │ features→ 均線/量/指標/轉折/缺口 │──▶│ /stock/id 個股診斷       │
└────────────────────────────────┘   │ rules   → 規則庫 (每條附出處)   │   │ /backtest 策略回測       │
                                     │ scanner → 每日訊號              │   │ /portfolio 持股與提醒    │
        Postgres (Neon/Supabase) ◀───│ backtest→ 交易模擬              │   │ /rules    規則庫說明     │
                                     └─────────────────────────────────┘   └──────────────────────────┘
排程：GitHub Actions cron（週一~五 15:30 / 20:00 補跑）
即時運算：FastAPI（Railway）提供 回測 / 個股診斷 API；Next.js 部署 Vercel
```

- **為何拆兩段**：pandas 計算全市場 ~1,900 檔 × 10 年 OK，但不適合跑在 Vercel Function；Python 獨立服務 + 批次排程最單純。
- **圖表**：TradingView `lightweight-charts`（K 線、量、markers、price lines 可標轉折點/缺口/停損）。

## 2. 規則引擎（核心）

分三層，**每條規則都帶 `reason` 文字 + 書中章節出處**，讓網站能解釋「為什麼選到這檔」。

### 2.1 基礎特徵（features）
| 類別 | 欄位 | 書中定義 |
|---|---|---|
| K 棒 | 實體%、上/下影比、長/中/小紅黑（>6.5% / 3.5–6.5% / <3.5%）、1/2 價 | 3-1、3-4 |
| 均線 | MA5/10/20/60/120/240、方向（**扣抵**：今收 vs N 日前收）、排列、乖離 | 4-1、4-2、8-4 |
| 均線糾結 | N 日內多條 MA 價差 < x%（5/10/20 或 6 線） | 4-2 |
| 量 | 5 日均量、量比；攻擊量 ≥1.3、爆量 ≥2、窒息量 ≤0.5、天量 ≥前日 2~5 倍 | 7-2 |
| 轉折波 | MA5/MA10/MA20 正負價區取高低點（精確演算法） | 2-1 |
| 趨勢狀態 | 頭頭高底底高=多頭、頭頭低底底低=空頭、其餘=盤整；多頭確認/空頭確認日 | 2-2、2-3 |
| 關鍵 K | 大量長紅/長黑的 高/1/2/低 三價位，追蹤是否被突破/跌破 | 3-1、6-2 |
| 指標 | MACD(12,26,9)、KD(9,3,3)、RSI(6,12)、BIAS20、MA 通道 ±15%、布林(20,2σ) | 8 |
| 背離 | 以轉折點比對價格 vs MACD 柱群/K 值/RSI 的高低（KD 限 20~80） | 8-1~8-3 |
| 缺口 | 真缺口 / 隱形缺口、4 價位（上高/上沿/下沿/下底）、真/假封口、3 日 2 缺口 | 9 |
| 盤整區 | 箱型上/下頸線、盤整天數、是否在高檔/低檔（久盤）、假跌破/假突破 | 10-4、11-3、12-1 |
| 波段位置 | 自底部起算第幾波、累計漲幅、與 MA20 乖離（起漲/主升/末升） | 10-3、11-2 |
| 相對強度 | 個股 vs 大盤、類股 vs 大盤的 N 日報酬排名 | 10-5 |

### 2.3 過濾器
- **做多 10 大戒律**（2-2）、**做空 10 大戒律**（2-3）逐條判斷，結果顯示為 ✅/❌ 清單。
- **短線做多 SOP 6 項**（趨勢、3 線多排、站上 MA10/20、量 ≥1.3 倍、紅K實體 >2%、MACD/KD 輔助）。
- **淘汰法 11 條**（10-3）：沒走出底部、重壓不過、趨勢不明、沒量能、漲幅已達 1 倍、遇壓大量長黑、指標背離+頭頭低、法人連續賣超、爆量不漲、有基本面沒技術面。
- **4 基**（10-3）：熱門類股、股本 < 50 億、營收成長、法人買超 — 作為加分項而非硬過濾。
- **大盤濾網**（10-5）：做多需大盤站上月線且月線上揚；做空需大盤在月線下且月線下彎。
- 流動性：採日均成交量濾網，預設近 20 個交易日日均量 ≥ 1,000 張（含訊號當日完整收盤資料；期間與門檻可調）；股價 ≥ 5 元（可調）。股票池排除全額交割與處置股；ETF 與 KY 不預設排除。特別報價法的「當日 1,000 張」保留為方法說明，不取代使用者選定的日均量濾網。
- 做空額外：須可融券（`stocks.can_short`）。

### 2.4 出場模組（回測與持股提醒共用）
| ID | 規則 | 出處 |
|---|---|---|
| `X-STOP-ENTRY-LOW` | 收盤跌破進場 K 最低點（上限 7%） | 2-2 |
| `X-LOWER-HIGH` | 收盤出現頭頭低 | 2-2 |
| `X-MA5-AFTER-10` | 獲利 >10% 後收盤跌破 MA5 | 2-2、4-3 |
| `X-CLIMAX` | 獲利 >20%，或急漲 3 天後大量長黑覆蓋/吞噬 → 當日出 | 2-2 |
| `X-3MA-SCALE` | 破 MA5/10/20 各出 1/3，站回各補 1/3 | 4-3 |
| `X-K-LINE` | 收盤跌破前一日低點（K 線戰法） | 3-6 |
| `X-BB-MA5` | 沿布林上軌時，黑K跌破 MA5 停利 | 8-5 |
| `X-GAP-FILL` | 進場缺口被真封口 | 9-5 |
| `X-SWING-SOP` | **短線波段 20 條守則**（停損 5%、>10% 破 MA5、>20% 大量長黑減半/全出、橫盤破底出、週線遇壓破 MA5 出…） | 11-2 |
| `X-LONG-MA20` | 長線：>10% 收盤破 MA20 停利；漲約 1 倍後不做長線 | 11-2 |
| `X-HOT-STOCK` | 飆股續抱：不破前 2 日低、不破 MA3、未出黑K；量大增開高走低黑K → 賣 | 11-2 |
| `X-MAX-LOSS` | 絕對停損：虧損 ≥ 使用者設定上限（預設 10%，介面可調）、或盤整區布局跌破、或趨勢反轉確認 | 11-1、12-3 |
| 空單鏡像 | 進場黑K高點停損、底底高回補、獲利>10%突破 MA5 回補… | 2-3 |

**策略 = 進場規則 + 過濾器 + 出場模組** 的組合，網站上可自由組裝並回測。

**已確認的停損行為**：策略停損先觸發先出場；最大虧損比例作為最後上限，達到上限即出場，不等待策略停損。上限預設 10%，必須可在介面設定並保存為參數，規則引擎不得寫死 10%。回測與持股提醒共用此參數；每次回測保存當次設定，供結果重現。日K資料的判斷與成交時點需在回測中明列，停損上限不代表跳空時能保證該比例成交。

### 2.5 資金與部位管理（11-1、12-1~12-3）
- **大盤水位表**：依加權指數狀態自動建議總投入比例（多頭頭頭低 5 成、空頭確認 4 成、中期空頭 3 成、長期空頭 2 成、空轉多確認 3 成、4 線多排前 4~5 成、4 線多排 6~8 成、末升段 5 成）。最多投入 9 成。
- **集中持股**：同時 2~5 檔（初階 1~2、進階 1~3、終極 2~5）。
- **加碼規則**：初升/主升起漲後橫盤（5% 內）或下跌未破停損，再放量紅K → 可加碼，加碼單另設停損；波段已漲 10% 以上不加碼。
- **套牢監控**：持股跌幅 > 5% 列為警示股；虧損 10/20/30% 標示輕/中/重度套牢。
- **牛步股汰換**：持有 1 週~半個月漲幅 < 5% 提示換股（強勢比漲勢重要）。

## 3. 頁面規劃

### `/scan` 今日掃描
- 分頁：做多候選 / 做空候選 / 觀察名單（右腳、糾結中）/ 持股警示。
- 每列：代號、收盤、觸發規則 chips、10 戒律通過數、建議停損價與風險%、量比、趨勢段位估計。
- 點擊 → 個股診斷。可存成自訂掃描條件。
- 頂部顯示**大盤狀態 + 建議投入資金比例**、**今日最強/最弱 3 類股**（10-5）。
- 預設掃描組合（對應書中方法）：六六大順、4基10技、強勢飆股第 2 波、底部鎖股（未卜先知）、6 種高勝率型態、33 種贏家圖像、12 口訣警示。
- 「收盤後工作」頁籤：漲幅/跌幅 ≥3.5% 前 50 檔、量增前 100 檔，套用淘汰法後列出（10-3、10-5）。

### `/watchlist` 鎖股資料夾（10-3、10-5）
- 底部鎖股（未卜先知 5 觀察）與強勢股自動入選；可手動加入。
- 每日更新：距突破點/壓力的距離、強弱排序、觸發進場時通知；跌破條件自動移出。

### `/stock/[id]` 個股診斷
- K 線圖自動標註：轉折高低點、頭頭高/低、均線、缺口（4 價位線）、關鍵大量 K 的 1/2 價、K 線組合、背離。
- 右側「書本檢查表」：依**六六大順**順序（趨勢 → 位置 → K線轉折 → 均線 → 成交量 → 指標）+ 缺口、支撐壓力，各給狀態與一句話理由。
- **選股評量表格**（10-3）：週/日波型、位置、K線、均線、量、週/日 MACD 與 KD、支撐、壓力、背離、融資融券、法人、型態 → 系統建議策略（短線守 MA5、長線守 MA20、目標價）。
- 出現的 33 種贏家圖像 / 12 口訣直接標在圖上。
- 日 / 週 / 月 線切換（書中多處要求週線不遇壓、月線突破）。

### `/backtest` 策略回測
- 選策略組合、參數、股票池、期間；手續費基準 0.1425%，預設 2.8 折（倍率 0.28，每邊 0.0399%）。介面可設定其他手續費率並保存不同券商費率方案，每次回測選擇方案並保存實際費率；第一版不含當沖。另計證交稅與融券費。
- **已確認預設**：初始資金新臺幣 300,000 元；最大虧損比例預設 10%，可在介面調整並納入回測參數。
- 結果：權益曲線、勝率、平均報酬、盈虧比、最大回撤、持有天數分布、逐筆交易（可點開看當時圖）。
- 多策略比較（例：MA5 法 vs 3 均線分批 vs K 線戰法 vs 短線波段 20 條 SOP）。
- 資金模型可選：固定金額 / 大盤水位表 / 最多 N 檔集中持股。
- 對照 **5 種贏家獲利方程式**（12-1）：顯示實際「年交易次數、勝率、平均停利%、平均停損%、年獲利」與書中目標（如 20 次、50%、+7%、−5%、20%）的差距。

### `/portfolio` 持股追蹤
- 輸入進場日/價/方向/張數 → 每日收盤後跑出場模組，顯示「續抱 / 減碼 / 出場」與原因。
- 套牢警示（跌幅 >5%）、牛步股汰換提示、目前總投入比例 vs 大盤水位建議。
- **目標管理**（12-2）：選擇階段（初階 月 2% / 進階 月 5% / 終極 月 8.33%），追蹤每月實際報酬與達成率。
- **已確認預設**：初階、月目標 2%；書中的初階 50 萬元為參考案例，不覆蓋使用者確認的回測初始資金 30 萬元。
- 設定介面提供最大虧損比例（預設 10%），由持股出場檢查讀取保存設定。
- 通知：LINE 官方帳號 Messaging API。Channel access token 與接收者 user ID 由環境變數設定，不納入 Git；接通與實際測試通知於 P5 處理。

### `/rules` 規則庫
- 每條規則的白話說明、示意圖、參數、對應章節 — 兼作學習筆記。

## 4. 開發階段

| 階段 | 內容 | 驗收 |
|---|---|---|
| **P0 資料** | 股票清單、10 年日K回補、每日增量、除權息表、還原價 | 資料完整率、與看盤軟體抽樣比對 |
| **P1 特徵 + 測試** | 2.1 全部特徵；**用書中範例圖當黃金測試**（如 精測6510 2019/08 盤整突破、國產2504 2016/11 竭盡缺口、華夏1305 缺口 4 價位；12-4 的 33 圖多為 2024 年範例，如 凱崴5498、元禎1725 一日反轉） | 測試能重現書中標註 |
| **P2 個股診斷頁** | Next.js + 圖表標註 + 檢查表 | 肉眼核對規則正確性 |
| **P3 掃描器 + 排程** | 規則/過濾器、大盤水位、鎖股資料夾、每日 cron、`/scan` `/watchlist` | 每日 16:00 前出結果 |
| **P4 回測** | 事件驅動回測、成本、參數掃描、`/backtest` | 書中範例績效可大致重現（如 MA5 法） |
| **P5 持股與通知** | `/portfolio`、出場檢查、通知 | 模擬持股收到正確提醒 |

建議先做 P0→P2：個股診斷頁是驗證規則是否寫對最快的方式。

## 5. 需要近似處理的主觀規則
| 書中概念 | 程式化做法 |
|---|---|
